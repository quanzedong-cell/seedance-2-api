## 支持能力

- 文生视频与图生视频
- 首尾帧、参考图一致性与多镜头叙事
- 人物短剧、商业广告、电商、教育和内容生产工作流
- 常用清晰度与画幅规格，具体以接入时可用模型列表为准
- 统一 API 接入，减少渠道和模型变更对客户端的影响
- 企业额度、用量统计、技术支持与发票流程

## 接入流程

1. 提交业务场景、预计用量、地区和所需规格。
2. 确认可用模型、测试额度与技术接口。
3. 完成商务报价、合同与开票资料确认。
4. 获取生产凭证，完成联调后上线。
